# GenCompass

Рабочий веб-прототип Lumen Genomics по `GenCompass_PRD_Design.md` от 04.09.2026, с правками пользователя из браузера.

Реализованы данные пациента и приёма; восемь открытых групп клинических признаков; закреплённая полоса этапов; мгновенный демо-индекс; объяснение вкладов и источники; сохранение черновиков и результатов в D1; история и повторное редактирование; направление, TXT и печать / сохранение PDF через диалог браузера. Русский интерфейс адаптирован к десктопу и планшету.

## Запуск

Требуется Node.js 22.13+.

```sh
npm ci
npm run db:migrate:local
npm run dev
```

Локальный адрес выводится сервером (обычно http://localhost:3000).

```sh
npm run test
npm run typecheck
npm run lint:app
npm run build
```

`npm run lint` также проверяет поставляемый каталог компонентов стартера и сообщает его исходные замечания. `lint:app` проверяет авторский код приложения. Компоненты стартера не редактировались для подавления этих замечаний.

## Модель и данные

- `lib/clinical-data.json`: клинические признаки, демовеса и проверенные источники NHS, ACMG, TIDE/Van Karnebeek, RCH, MPSE.
- `lib/model.ts`: максимум выбранных весов внутри каждой категории, сумма максимум 100. Диапазоны 0–24 / 25–49 / 50–100 демонстрационные.
- Пустой/неизвестный ввод не обозначает отсутствие признаков. До известного ответа показывается «Нет данных». Состояния «не заполнено», «нет данных», «не выявлены» сохраняются отдельно.
- Веса и пороги отсутствовали в PRD. Это не валидированный медицинский алгоритм и не вероятность диагноза. Источники подтверждают контекст признаков, но не веса. MPSE/TIDE не выдаются за используемый алгоритм.
- Клинический календарь использует `Asia/Almaty` одинаково в браузере и сервере; возраст считается на дату приёма. Часовой пояс задаётся в `lib/patient.ts`.
- История хранится в D1, временный несохранённый ввод — в `sessionStorage`. Ошибка сохранения не очищает форму. Восстановление сохраняет структурно корректный черновик даже при незавершённой валидации отдельных полей.
- Создание новой оценки всегда использует новый ID. Изменения существующего случая обновляют его сохранённую запись.
- `.openai/hosting.json` связывает проект с закрытым Sites-пространством. Локальная тестовая база `.wrangler/` не публикуется. Доступ сайта должен оставаться закрытым владельцу; аккаунты клиники/разделение доступа между врачами не реализованы.

## Границы готовности

Это функциональный прототип интерфейса. Для клинической эксплуатации необходимы утверждённые веса и пороги, валидация, регламент обработки медицинских данных и аудит доступа. Английская локализация, МИС/EHR, аккаунты клиники и автономная работа без соединения не входят в эту сборку. PDF создаётся штатным диалогом печати, направление не отправляется внешнему получателю.

Два WebMCP-инструмента используют состояние экрана: чтение текущей оценки и заполнение несохранённых признаков. Они не сохраняют запись и не отправляют направление.
